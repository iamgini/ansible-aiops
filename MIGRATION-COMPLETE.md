## Technical Changes

### API Endpoint Changes

**Before (Maya):**
```yaml
maya_api_url: "http://localhost:8000/api/v1/events/generate"
```

**After (Code Assistant):**
```yaml
lightspeed_url: "http://localhost:8000/api/v0/ai/generations/"
lightspeed_token: "${AAP_BEARER_TOKEN}"
```

### Request Format Changes

**Before (Maya):**
```yaml
body:
  event_type: "{{ event_type }}"
  description: "{{ event_description }}"
  host: "{{ event_host }}"
  severity: "{{ event_severity }}"
```

**After (Code Assistant):**
```yaml
headers:
  Authorization: "Bearer {{ lightspeed_token }}"
  Content-Type: "application/json"
body:
  text: "{{ lightspeed_prompt }}"  # Structured prompt with requirements
```

### Response Format Changes

**Before (Maya):**
```yaml
maya_response.json.playbook
maya_response.json.confidence_score
maya_response.json.event_id
maya_response.json.validation_passed
maya_response.json.generation_metadata.model
```

**After (Code Assistant):**
```yaml
lightspeed_response.json.playbook  # or .content
# Note: No confidence_score, event_id, or metadata fields
# Added manual validation instead
```
